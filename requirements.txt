# Dashboard TB Recife — intenção: faixas de versão que o código suporta.
# (sem pygwalker: Análise Livre é o Apache Superset embutido via iframe, ver
# app.py e docs do dashboard-tb-v4)
#
# O que é instalado de fato está em requirements.lock.txt — é de lá que o
# Dockerfile instala. Mexa aqui só para mudar a faixa; depois regenere o lock
# (ver README, seção Dependências).
#
# Antes destes tetos as faixas eram largas demais (`pyarrow>=14.0`,
# `plotly>=5.20`, `duckdb>=0.10`) e a produção já tinha atravessado plotly
# 5 → 6 e pyarrow 14 → 25 sem que isso fosse decidido.
#
# ATENÇÃO — diferente dos outros painéis da família, este lock NÃO descreve o
# que a VM roda hoje. O container em produção ainda é a versão com PyGWalker;
# o código aqui já é a versão Superset. O lock acompanha o código, não a VM:
# o primeiro deploy depois disto vai instalar um conjunto bem menor (sai toda
# a árvore do PyGWalker: ipython, jupyter-widgets, wasmtime, sqlglot…).
# Isso é a correção, não um efeito colateral — mas é mudança real de imagem.
streamlit==1.35.0
